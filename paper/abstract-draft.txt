AI agents increasingly revise their skills, memories, tools, and workflows. A change that helps one task can break a dependent workflow, expand permissions, or restore an artifact that was previously withdrawn. SSEVOH-DSL makes proposed changes explicit and separates proposal generation from permission, independent validation, and controlled deployment. Its reference implementation combines a small declarative language, dependency and provenance analysis, a bounded lifecycle verifier, and an atomic metadata sandbox. HeartBench provides labeled evolution scenarios and an evaluation protocol for five open-weight models across three Canadian research clusters. This development draft distinguishes executed implementation checks from pending empirical findings. Its guarantees concern the stated metadata semantics and finite models, rather than arbitrary agent code or production deployments.
