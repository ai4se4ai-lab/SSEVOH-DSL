# Implementation and acceptance report

The formal core and the real Harness² integration are implemented. Both full empirical campaigns completed on Fir and Rorqual after formal verification and independent smoke qualification. Diagnostic reanalyses preserved all original samples and original summary values. A separately labelled post hoc strict request-fidelity metric adds snapshot, evidence and condition checks; it does not replace the independent safety oracle. See the [plain-language guide](research-overview.md), [claim/evidence matrix](claim-evidence-matrix.md) and [manuscript](ieeesoftware/main.tex).

| Area | Completed work and evidence | Scope and remaining limits |
|---|---|---|
| DSL/compiler | Located diagnostics, immutable typed/canonical IR, seven component kinds, update/withdraw/rollback, dependency/provenance checks and operator-owned permissions | Single target per metadata evolution; arbitrary predicates, temporary grants, creation/deletion and approval hierarchies are unsupported |
| Core assurance | Source-scoped release: 62 tests, 248,832 independent one-step cases, 19,620 bounded history transitions, 6,880 anchored replays; four exact TLC/Python graphs and five faulty variants | Relative bounded soundness/completeness, not an unbounded refinement or generated-code safety theorem |
| Trusted runtime | Isolated candidates, evidence/context-bound one-use approvals, atomic metadata commit, monotone version withdrawal, quarantine, checked rollback and anchored trace/replay | Trusted pure terminating validators and host isolation assumed; no durable service restart or cross-host transaction proof |
| Real integration | Unmodified Harness² pin; 70 upstream tests, 32 integration/worker tests, four exact publication-model graph comparisons and six faulty variants | Real admission/execution/library seams, finite executable catalog and bounded ledger backend; general coding executors and professional benchmarks unsupported |
| Primary study | 500 raw model outputs, 500 B0–B3 records, 750 ablation records and 180 graph/concurrency records; full matrix and transfer checks passed | 91 outputs independently evaluable: 73 disallowed, none deployed; three models produced no syntax-valid raw DSL under the fixed protocol |
| Integration study | 900 deterministic records, 25 model streams and 50 task observations; shared and authority-only lifecycle denominators separate | C3 retained 15/15 legitimate fixture trials and admitted 0/45 disallowed trials. Evolved and frozen model workflows both achieved 0/50 task successes; usefulness remains unestablished |
| Costs/scaling | Scheduled latency, traced allocation and one-winner concurrency tables; 500-component single-contender median batches 0.470–0.773 s across shapes | Traced Python allocations exclude native/GPU memory; no asymptotic or multi-host throughput claim; admission-only baselines are not equivalent deployment pipelines |
| HPC operations | Pinned use-hpc, source/config/model identities, three-site SSH/fleet scripts, Slurm dependencies/arrays, unique ownership, GPU residency, logs, resume checks and verified transfers | Fir/Rorqual qualified before the 45-minute deadline. Narval’s later partial observations and censored GPU cells are separate from the frozen assignment |
| Reanalysis | Three scheduled CPU cells added protocol diagnostics and legitimate-action timings; input hashes verified; all original metrics unchanged; initial analyses retained | A lost SSH submission acknowledgement was reconciled from the remote job ledger without resubmission |
| Cross-site output checks | Scheduled metadata report compared 24 identity-matched pairs, including completed partial Narval cells | All text/decisions matched but both outputs were syntax-invalid; one-context comparison supplies no broad useful-generation replication claim |
| Publication | Main article and seven independent supplements; generated numeric fragments/tables; word/abstract ceiling checked | Review build uses the documented article fallback when publisher class assets are absent; external label review and broader useful-agent validation remain open |

Current source-scoped evidence is in [core readiness](../formal/assurance/results/readiness.json), [integration readiness](../integrations/harness2/evidence/readiness.json) and [primary-worker readiness](../experiments/evidence/core-study-readiness.json). The current test rerun skips the closed-empirical-gate test while the explicit research gate is open; the original formal release tested the closed gate before the current empirical campaigns. Mocked transport tests are unit evidence, never GPU observations.

The collected artifacts are [primary results](../artifacts/benchmark-results/full-campaign/analysis/summary.md), [integration results](../artifacts/benchmark-results/harness2-full/analysis/summary.md), raw samples and completeness manifests in their parent directories, and source/config/job/transfer records under `hpc/fetched`. The local monitor displays audit age separately from fetch age. The earlier controller stays disabled and earlier exploratory data are not pooled with these studies.

Known research gaps include independent human label review, richer semantic validators, broader artifact domains, calibrated output protocols, unrestricted executor isolation, durable recovery and evidence of useful model-driven improvement. No statistical significance or production-safety claim is inferred from the two ledger tasks or from malformed-output rejection.
