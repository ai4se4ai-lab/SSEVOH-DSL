# Publication requirements checked 2026-11-09

The official IEEE Software call confirms a 4,200-word ceiling, with 250 words per figure/table, excluding up to 15 references and biographies; abstract at most 150 words. It also requests three actionable practitioner insights.

Source: https://www.computer.org/digital-library/magazines/so/cfp-ieee-software

The supplied IEEEcsmag source is preserved as `docs/ieeesoftware/CsMag_template.tex`. Its publisher class and upmath package were not included in this repository and are not installed locally. The manuscript uses IEEEcsmag when available and an explicitly marked article-class review fallback otherwise. A fallback PDF is not validated publisher typography.

The manuscript remains a development draft until the five-model, repeated three-cluster evaluation is collected. Local tests and smoke observations are labeled as such; generated result text records pending measurements without substituting estimates.
