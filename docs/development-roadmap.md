# Acceptance roadmap

1. Architecture and mathematical lifecycle before implementation.
2. Lexer/parser, source diagnostics, immutable AST/IR, type/reference/policy validation and five examples.
3. Deterministic assurance, trusted validators, single-use approval and atomic sandbox deployment.
4. Independent bounded lifecycle exploration, negative mutants, runtime conformance tests.
5. Independently labeled HeartBench scenarios, baselines, ablations, fault/concurrency tests.
6. Qualify Fir, Narval and Rorqual using equivalent repeated GPU smoke jobs. Block full runs until real successful qualification and frozen model digests exist.
7. Distribute disjoint model cells by reliability-adjusted completion time, monitor all sites, persist raw data and hashes.
8. Analyze paired/repeated measurements and generate publication artifacts. Missing empirical results remain explicitly pending.
